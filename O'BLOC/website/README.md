# O’BLOC — Private Lounge

Премиальный адаптивный лендинг с интерактивной WebGL-сценой кальяна.

## Архитектура сцены

- `components/HookahScene.tsx` — изолированный клиентский 3D-модуль на React Three Fiber.
- Кальян собран из PBR-примитивов: керамика, металл, transmission-стекло и полупрозрачная вода.
- Дым — оптимизированная система частиц с несколькими слоями плотности и плавным спиральным движением.
- Пузырьки — компактный пул частиц внутри колбы без создания объектов на каждом кадре.
- Угли используют пульсирующий emissive-материал, отдельный источник света, искры и Bloom.
- Камера проходит из верхнего macro-ракурса в финальную hero-позицию и едва реагирует на курсор.
- На мобильных уменьшается количество частиц, ограничивается pixel ratio и сохраняется облегчённое освещение.

## Запуск

```bash
npm install
npm run dev
```

## Продакшн и Dokploy

В проекте есть multi-stage `Dockerfile`, а Next.js собирается в режиме `standalone`. В Dokploy достаточно подключить GitHub-репозиторий, выбрать сборку из Dockerfile и открыть порт `3000`.

Перед публикацией задайте `NEXT_PUBLIC_SITE_URL`, замените адрес, телефон, соцсеть и ссылки на отзывы в `app/page.tsx`, а форму бронирования подключите к CRM или Telegram-боту.
